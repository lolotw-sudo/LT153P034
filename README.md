# 🏆 客網新進人員訓練班第034期

把訓練課程的成績表變成一個會動、會歡呼、會讓學員想往上爬的**互動排位榜**。

作業、平時加分、考試一路累積成「累積總分」，17 位學員即時排名；
期末再依配分算出滿分 100 的學期成績，直接輸入學習系統。
資料放在 Google 試算表，你在試算表改分數，排行榜按一下同步就當場重新洗牌。

## 快速開始

直接用瀏覽器打開 `index.html` 就會跑起來 —— 試算表已經接好了，開啟時會自動同步。
要放給學員用手機看，把整個資料夾丟上 GitHub Pages 或任何靜態空間即可 —— 沒有任何相依套件、不需要伺服器。

### 換班級 / 換試算表

改 `index.html` 最下面那段設定就好，不用動其他檔案：

```js
window.ARENA_CONFIG = {
  sheetId: '1aO5WitIyYTfxgzR5OSeHSj5ByeAfmzTQq2J-Ov4xxM8',
  sheetName: '',              // 總表分頁名；留空讀第一個分頁
  logSheetName: '表現紀錄',    // 加減分流水帳的分頁名；留空＝不使用
  perfTarget: 70,             // 活躍度的滿分目標（累計加到幾分算滿）
  weights: { quality: 30, performance: 20, exam: 50 },   // 各項配分，相加＝滿分
  settingsPasswordHash: '2b214c...'   // 「設定」分頁的密碼（SHA-256）
};
```

`sheetId` 就是試算表網址中間那一段：
`https://docs.google.com/spreadsheets/d/【這一段】/edit`

也可以不改檔案，直接在網頁的「設定」貼上新連結 —— 那會存在該台瀏覽器裡，只影響你自己那台。
寫進 `index.html` 的才是所有人打開都會看到的預設值。

### 設定分頁的密碼鎖

「設定」分頁預設是鎖住的，要輸入密碼才會展開，避免投影機或共用電腦上有人隨手改到權重、
或看到試算表連結。解鎖狀態存在 `sessionStorage`，**關掉瀏覽器就自動恢復鎖定**；
也可以在設定裡按「🔒 立刻重新鎖定設定」。

換密碼：算出新密碼的 SHA-256，貼進 `settingsPasswordHash`。

```bash
# macOS / Linux
printf '你的新密碼' | shasum -a 256
```

把 `settingsPasswordHash` 設成空字串 `''` 就完全不上鎖。

> **這個鎖擋得住什麼、擋不住什麼**
>
> 這是純前端靜態網站，沒有伺服器可以驗證密碼。存的是 SHA-256 雜湊而不是明碼，
> 所以密碼不會被一眼看到，但**懂開發者工具的人可以繞過**。
>
> 更重要的是：**鎖住設定分頁並不會隱藏試算表網址**。試算表 ID 本來就寫在
> `index.html` 裡（網頁必須靠它讀資料），任何人「檢視原始碼」都找得到。
>
> 另外，權重這類設定存在各自瀏覽器的 localStorage，
> 學員在自己手機上改動只會影響他自己看到的畫面，不會動到別人的。
> （回合紀錄是例外：它寫在試算表，全班共用，所以「存檔回合」按鈕要解鎖才按得動。）
>
> 所以這個鎖的定位是「防手癢」，不是存取控制。真的不想讓成績外流，
> 唯一可靠的做法是**在試算表裡就用代號而不是真名**。

## 自己準備試算表

試算表用**兩個分頁**：一個放學員總表，一個放活躍度的加減分流水帳。

### 分頁一：學員總表

| 座號 | 姓名 | 組別 | 單位 | 頭像 | 作業1 | 作業2 | 作業3 | 考試成績 |
|------|------|------|------|------|-------|-------|-------|----------|
| 01 | 陳彥廷 | 雷霆隊 | 台北營運處 | 🦊 | 88 | 82 | | 85 |
| 02 | 林佳蓉 | 疾風隊 | 新北營運處 | 🐯 | 95 | 0 | | 91 |

欄位順序不拘，靠表頭名稱比對；沒有的欄位留著不填或整欄不建都可以。

- **座號**：選填，但填了才能用「座號＋姓名」的下拉選單記加減分（見下）
- **姓名**：必填，也是每位學員的身分依據
- **組別**：填了才會出現「公會戰」分頁；留空就只跑個人榜
- **單位**：選填。學員的服務單位（例：桃園營運處），顯示在個人戰績卡的公會標籤旁邊，
  給指導員一眼看出這是誰家的人；留空就不顯示那個標籤
- **頭像**：一個 emoji；留空會自動配一隻動物
- **作業1～3**：0–100，三份**等權**，各佔學期成績 10 分（網站上顯示為「練習賽1～3」）
  - **留白 = 還沒評分**，那 10 分還沒開放 —— 所以開課初期只發了一份作業，分數也不會被稀釋
  - **漏交要明確填 0**，那會實實在在算成 0 分。留白和 0 意義完全不同，別混用
- **考試成績**：0–100（網站上顯示為「終極考驗」；只用於學期成績配分，畫面上的第三個維度與徽章優先顯示刷題均分）

沒有作業1～3 欄時，會退回讀舊的單欄「作業成績」，舊試算表不會壞。

### 分頁二：表現紀錄（加減分流水帳）

| 日期 | 堂次 | 學員 | 加減分 | 事由 | 老師 |
|------|------|------|--------|------|------|
| 10/03 | 第1堂 服務禮儀 | 01 陳彥廷 | 2 | 主動示範情境演練 | 王老師 |
| 10/05 | 第2堂 客訴處理 | 02 林佳蓉 | -1 | 上課使用手機 | 李老師 |

上完一堂課就在**最底下追加幾列**，一位學員一列；同一堂課同一人可以記多列，也可以記負分。
必要的只有「學員」與「加減分」兩欄，其餘留空也能跑，但填了才有明細可看。

### 「學員」欄設成帶座號的下拉選單

在總表最右邊加一欄 `選單`，第二列填這條公式（假設座號在 A 欄、姓名在 B 欄）：

```
=ARRAYFORMULA(IF(B2:B="","",TEXT(A2:A,"00")&" "&B2:B))
```

會自動長出「01 陳彥廷」「02 林佳蓉」。再到表現紀錄的「學員」欄設
**資料 → 資料驗證 → 從範圍選取**，指向這一欄即可。

比對是**姓名與座號雙軌**的，這幾種寫法系統都認得：

| 寫法 | 認得嗎 |
|------|--------|
| `01 陳彥廷` | ✅ 標準寫法 |
| `1. 陳彥廷` / `1、陳彥廷` / `1-陳彥廷` | ✅ 分隔符號空白、點、頓號、減號、括號都吃 |
| `01`（只有座號） | ✅ 靠座號對回總表 |
| `陳彥廷`（只有姓名） | ✅ 靠姓名對 |

> 對不上的紀錄不會被默默吞掉——同步訊息會明確列出是哪幾個名字、告訴你那些分數沒有計入。

分頁名稱預設是「表現紀錄」，可以在「設定」裡改；**留空就完全不讀這個分頁**，活躍度改回讀總表的欄位。

### 共用設定

右上角「共用」→ 一般存取權改成 **「知道連結的任何人」→ 檢視者**（這步沒做，網頁讀不到資料）。
然後複製網址列的整段連結，貼到網頁的「設定 → Google 試算表連動」，按 **儲存並同步**。

欄位名稱有做模糊比對：總表寫「作業1」「作業一」「練習賽1」「hw1」都認得，「表現」「活躍」「考試」「終極」或英文
`performance` / `exam` 也可以；流水帳寫「學員」「加減分」「事由」等即可。

## 六個模式

| 模式 | 做什麼 |
|------|--------|
| **個人榜** | 主畫面。前三名頒獎台 + 17 人排位列，名次變動時卡片會實體滑動超車。每列三條進度條＝練習賽／活躍度／**刷題均分**（跟能力三角同一組維度；讀不到刷題紀錄時第三條退回終極考驗） |
| **公會戰** | 依「組別」自動分組，公會分數 = 公會內平均累積總分 |
| **個人戰績卡** | 點任一位學員 → 公會與**服務單位**、能力三角雷達圖（練習賽／活躍度／**刷題平均得分**；讀不到「刷題紀錄」分頁時第三軸退回終極考驗）、三份作業各自的分數、名次走勢、徽章牆，最後是**加分明細時間軸**（哪一堂、什麼事由、加幾分） |
| **賽季日誌** | 一週一段的班級歷程：那幾天上了什麼、導師側記，加上那一週的學習分析報告（數據卡、學員原話、成效、改善方向）。右上角連到 Slido 匿名話牆 |
| **頒獎典禮** | 全螢幕，只揭曉**前 6 名**（白金以上），從第 6 名倒數到第一名。前三名放慢節奏、冠軍噴彩帶配樂 |
| **刷題練習** | 學員自己選名字 → 隨機抽 10 題 → 交卷計分。每天 3 次，練習次數自動計入互動成績 |

## 兩套數字：排行榜看累積，成績單看比重

這是刻意的設計，兩個數字回答不同問題。

### 排行榜：累積總分

```
累積總分 = 已評作業分數相加 + 累計加減分 + 考試分數
```

直接相加，不換算、不設上限。每交一份作業、每拿一次加分，數字就往上長，
期末會遠遠超過 100（三份作業 + 考試 + 加分，大概落在 350 上下）。

**還沒評分的作業就是還沒加上去，不是 0 分。** 所以：

- 期中只評了一份作業時，分數不會被還沒發生的項目稀釋
- 分數**只會往上爬**，學生不會遇到「我沒退步，分數卻掉了」

段位依**名次百分位**（前 6% 王者、18% 鑽石、36% 白金、60% 黃金、85% 白銀，其餘青銅），
不看絕對分數——累積總分整個賽季都在長，用固定門檻的話期初全班青銅、期末全班王者。

### 成績單：學期成績（滿分 100）

```
學期成績 = 練習賽 × 30% + 活躍度 × 20% + 終極考驗 × 50%
```

| 項目 | 配分 | 0–100 怎麼來 |
|------|------|--------------|
| 練習賽 | 30 | 三場**等權平均**，還沒評的不列入 |
| 活躍度 | 20 | 累計加減分 ÷ **滿分目標 70**，封頂 100、低於 0 歸零 |
| 終極考驗 | 50 | 直接讀欄位 |

配分在「設定 → 學期成績配分」用滑桿調整，三項相加就是滿分。

這份成績在**「設定 → 學期成績」**，按「複製成績清單」會複製成
`座號 / 姓名 / 學期成績` 的 TSV，直接貼進學習系統或試算表。
設定頁有密碼鎖，**學生看不到這一頁**。

> 期末若只出了兩份作業也不用調任何設定——練習賽成績本來就只平均已評的那幾場。

### 兩者排序不完全一致

累積總分裡三份作業共 300 分、考試只有 100 分，比重跟配分 30/20/50 不同，
所以排行榜名次跟學期成績高低可能有出入。這是刻意接受的：
**排行榜是給學生看的遊戲，學期成績是給行政系統的數字**，兩者用途不同。

## 賽季日誌

班級的完整歷程，一週一段。用**兩個新分頁**餵資料，兩個都是選配的——
沒建立就只是那一塊不顯示，其他功能完全不受影響。

### 分頁三：課程表（一堂一列）

| 週次 | 日期 | 時間 | 主題 | 講師 | 側記 |
|------|------|------|------|------|------|
| 第1週 | 8/12（三） | 9:10–10:00 | 訓練課程說明 | 李怡菁 | 開訓第一天，17 位夥伴全到齊⋯ |
| 第1週 | 8/12（三） | 10:10–14:20 | 通訊系統概要 | 蕭毅 | |
| 第1週 | 8/13（四） | 9:10–16:20 | 電信線路工程基本概要 | 劉時淼 | 時淼老師的投影片做得非常清楚⋯ |

- **主題**是唯一必填的欄位，其餘留空都能跑
- **日期**填什麼就顯示什麼，`8/12（三）` 這種寫法最好讀
- **時間**是照片歸課的依據（見分頁五）。留空的話那一天的照片就只掛在日期底下，不分堂
- **側記掛在它自己那一堂課底下**：哪一堂想寫就填在哪一列，同一天寫好幾則也可以，各自顯示
- 週次照 `第1週` `第2週` 寫，**第1週在最上面**，一天一天往下讀
- **整期可以一次填滿**：還沒上到的日子不會顯示，上到那天自己會出現

> 課程 WBS 的「逐堂檢核」分頁本來就有日期／時間／課程／講師，複製過來就好，不用重打。

### 分頁四：學習報告（一週一列）

從你的 Word 學習分析報告複製貼上，一週貼一列。

| 週次 | 期間 | 重點數據 | 摘要 | 學員回饋 | 成效評估 | 改善方向 |
|------|------|----------|------|----------|----------|----------|
| 第1週 | 8/12–8/14 | `參訓人數=17 人/問卷回收=100%/六堂平均=9.45 分` | （第一章） | （第四章，一則一行） | （第五章） | （第六章的學員版） |

- **重點數據**格式是 `標籤=數值`，用 `/` 隔開，要幾張卡就寫幾組
- **週次**必填（沒填的那一列會被略過），要跟課程表的寫法一致才掛得上去
- **學員回饋**與**改善方向**是「一格內多行，一行一則」。
  從 Word 複製整段後，**先雙擊儲存格進入編輯狀態再貼上**——
  直接點一下就貼，Google 試算表會把每一行拆散到好幾列。
  要手動補一行時，Mac 按 `⌘ + Enter`、Windows 按 `Alt + Enter`
- 每一欄都可以留空，留空就不畫那一塊
- **某一則回饋本身有換行時**（例如學員寫了一整封信），改成**用空行分隔每一則**，
  系統偵測到空行就會改用空行斷則，信裡的分段會原樣保留

### 分頁四之二：整期總評（選配，通常只有最後一週會填）

同一列再往右三欄，用來放「不屬於某一週、而是整期」的東西——期末能力自評、排課方式偏好那類。
三欄都留空就整塊不顯示，前面幾週正常留白即可。

| 整體數據 | 整體評估 | 整體回饋 |
|----------|----------|----------|
| `能說出FTTH／xPON架構=88.2%/能獨立完成細設圖=35.3%` | （整期的文字分析） | （質性回答，一則一行） |

- **整體數據**格式跟「重點數據」一樣，`標籤=數值` 用 `/` 隔開
- 網頁上會在該週報告的最後，用一條分隔線隔出「這一期整體來看」這一段


> **第六章建議寫「學員版」而不是照抄原文。**
> 原始報告的改善方向是寫給院方看的（「精簡講師數量」這類），
> 掛在學員看得到的公開網頁上，講師點進來會尷尬。
> 改成對學員說話——「你們說課程有重疊，第二週開始我把順序重新排過」——
> 同一件事，但學員讀到的是「我寫的回饋被看見了」。

### 分頁五：課堂相簿（自動產生，不用手填）

**你的日常動作只有一個**：手機相簿選幾張 → 分享 → Google Drive → 存到照片資料夾，大約 10 秒。

剩下的自動發生：`apps-script/課堂相簿索引.gs` 每小時把資料夾內容整理進「課堂相簿」分頁，
網站再把照片掛到賽季日誌對應的**那一堂課**底下。設定步驟寫在那支 .gs 的開頭。

| 日期 | 時間 | 檔案ID | 檔名 |
|------|------|--------|------|
| 8/12 | 14:12 | 1sV51t… | IMG_2313.heic |

- **日期與時間取 EXIF 拍攝時間，不是上傳時間**——照片隔幾天才上傳也會掛到對的那一天
- **照片歸到哪一堂課**：拿拍攝時間比對課程表的時間欄，落在「最後一堂已經開始」的那堂。
  下課空檔、午休、放學後拍的會歸給剛上完的那一堂
- **一堂課先排 12 張**（桌面剛好一整列），其餘收進「再看 N 張」，展開前不會下載
- **滑鼠移到縮圖會浮出大圖**；手機沒有這個行為，點一下開 Drive 原圖
- **沒有 EXIF 時間的照片**（截圖、翻拍）歸不到課，會掛在那一天的最後，不會消失
- **照片掛不上就不顯示**：課程表沒有那一天，那天的照片就不會出現（拍了非上課日的照片不會亂入）
- **iPhone 的 HEIC 可以直接丟**，Google 那端會自動轉成瀏覽器看得懂的格式，不用先轉檔
- 資料夾共用權限要設成**「知道連結的任何人 → 檢視者」**。
  給「編輯者」的話，任何拿到連結的人都能刪掉全班照片

> **關於偶發載不出來的照片**
> 實測 Google 的兩個圖片網址（`lh3.googleusercontent.com` 與 `drive.google.com/thumbnail`）
> 各有大約六分之一的機率會偶發失敗，但不會同時掛。
> 所以網頁是先用前者，載不出來自動換後者，兩個都掛才會留白。

### Slido 匿名話牆

在 `index.html` 的 `wallUrl` 貼上 Slido 連結，右上角就會出現「匿名話牆」按鈕，
點了在新分頁開啟。留空就不顯示這個按鈕。

## 刷題練習

學員自己在網站上練習的模式。**分數不進學習成績，但練習次數會加進互動成績**——
鼓勵多練，而不是鼓勵考高分。

### 運作方式

1. 學員打開網站 → 「刷題」分頁 → 從名單裡點自己的名字（不用密碼）
2. 系統隨機抽 10 題，一題一頁，選項順序每次都會重新打散
3. 交卷後立刻看到分數、逐題檢討、正解與**講義出處**（答錯時知道去翻哪一頁）
4. 每練完一次，後端自動在「表現紀錄」分頁寫一列加分，互動成績跟著長

**一天 3 次**由後端判定，不是靠瀏覽器記錄——換手機、清快取、開無痕都一樣是 3 次。

### 為什麼答案不會外流

題目送到瀏覽器時**不含正確答案**，對答案在 Apps Script 後端做。
學員按 F12 看原始碼也看不到答案。題庫放在試算表，不進這個公開的 repo。

### 為什麼讀和寫走兩條不同的路

| 動作 | 走哪條 | 為什麼 |
|------|--------|--------|
| 讀題目、查今日次數 | **gviz CSV**（跟同步學員名單同一條路） | 實測穩定、1 秒內回應 |
| 交卷（對答案、寫紀錄、加分） | **Apps Script** | 只有寫入非它不可，每回合只呼叫這一次 |

Apps Script 的網頁應用程式有個老毛病：後端跑久一點，Google 用來回傳結果的
一次性網址就會過期，直接回 404。**實測空機每四次約中一次**，跟設定無關。
所以能不用它的地方就不用它 —— 這也是為什麼抽題是在瀏覽器裡做的。

交卷那一次仍可能失敗，系統做了兩層保護：

1. **自動重試 4 次**（間隔遞增），多數學員不會看到錯誤
2. **每回合帶編號**：萬一寫進去了但回應弄丟，學員重按**不會**重複計次或加分
   —— 後端認得那是同一份卷（實測同一份連送 6 次只記錄 1 次）

真的四次都失敗時，畫面會停在最後一題、答案原封不動，等幾秒再按一次交卷即可。

### 答案為什麼不會外流

網頁讀題庫時用 `select A,B,C,D,E,F,G,H` 只取到題目與四個選項，
**讀不到第 I 欄「正確答案」**，對答案是在 Apps Script 後端做的。
學員按 F12 看原始碼也看不到答案。

### 設定步驟

1. 班級試算表 → 擴充功能 → Apps Script，貼上 `apps-script/刷題後端.gs`
2. 執行一次 `setup`，會自動建好「題庫」與「刷題紀錄」兩個分頁
3. 把題庫貼進「題庫」分頁，欄位如下：

```
科目	題號	主題	題目	選項A	選項B	選項C	選項D	正確答案	講義出處
```

「正確答案」填 `A`～`D`。題目多少題都可以，只要不少於 10 題。

4. 部署 → 新增部署作業 → **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**任何人**（少了這個學員會連不上）
5. 複製 `/exec` 結尾的網址，填進 `index.html` 的 `ARENA_CONFIG.quizApi`

想調整規則就改 `刷題後端.gs` 開頭的 `CONFIG`：

| 設定 | 預設 | 意思 |
|------|------|------|
| `QUESTIONS_PER_ROUND` | 10 | 每回合抽幾題 |
| `DAILY_LIMIT` | 3 | 一天幾次機會 |
| `POINTS_PER_PRACTICE` | 0.5 | 每練一次，互動成績加幾分 |

> 互動成績的滿分目標是 `perfTarget`（預設 70 分）。以每次 0.5 分、一天 3 次計，
> 全勤刷滿一天是 1.5 分——刷題可以補分數，但補不完，課堂表現還是主力。

## 賽季回合

「進步之星」和名次走勢圖需要有比較基準，所以按 **設定 → 🗂️ 賽季紀錄 → 存檔回合**（快捷鍵 `S`）會把當下的名次記錄成一個回合。

建議的節奏：每上完一個單元、或每週結束時存一次檔。存兩個回合以上，個人戰績卡就會出現名次走勢折線。

回合紀錄寫在試算表的「回合紀錄」分頁（見下），不是瀏覽器 ——
換電腦、清快取都不會不見，學員在自己手機上也看得到真實的名次變化。

因為是全班共用的，**按鈕放在「設定 → 🗂️ 賽季紀錄」裡**（設定有密碼鎖，學員打不開），
免得學員手癢按一下就把所有人的「本回合變化」洗掉。快捷鍵 `S` 一樣可用，但沒解鎖時會被擋下並跳到解鎖畫面。

### 分頁六：回合紀錄（自動產生，不用手填）

按「存檔回合」時由 Apps Script 寫入，一位學員一列：

| 時間 | 回合 | 標籤 | 座號 | 姓名 | 名次 | 累積總分 | 冠軍 | 存檔編號 |
|------|------|------|------|------|------|----------|------|----------|
| 2026-08-18 10:00:00 | 1 | 第 1 回合 · 2026/8/18 | 10 | 林禹廷 | 1 | 152.5 | ✔ | snap_… |

- **分頁不用自己建**，第一次存檔時後端會自動開好
- **存檔編號**是防重複用的：連線失敗自動重試時，同一次存檔不會被寫成兩個回合
- 讀回來時用姓名／座號對回目前名單，**已離班的人那幾列會被跳過**，不會弄壞舊回合
- 這個分頁沒設定後端網址（`quizApi`）時，存檔會退回只存在該台裝置，提示會講明白

## 流量統計（誰在看、看哪一頁）

想知道排位榜有沒有人在看、學員最常停在哪個分頁，接上 **Firebase Analytics**（骨子裡就是
Google Analytics 4）。設定完之後，五個分頁各自被開幾次、多少人、什麼時段來，
在 Firebase 主控台就看得到。

沒設定就完全不啟用 —— 網站每個功能照常跑，只是不會有數據。

### 設定步驟（約五分鐘，只要做一次）

1. 到 [console.firebase.google.com](https://console.firebase.google.com/) 用 Google 帳號登入，
   按「建立專案」，名字隨便取（例：`training-ranking`）。
2. 過程中會問「要不要啟用 Google Analytics」→ **一定要選「啟用」**，
   流量統計就是靠這個；Analytics 帳戶選現有的或新建都可以。
3. 專案建好後，在專案首頁按 **`</>`（網頁）** 圖示新增一個網頁應用程式，
   暱稱隨便取，「同時設定 Firebase Hosting」**不用勾**（我們用 GitHub Pages）。
4. 下一步它會給你一段 `const firebaseConfig = { ... }`，把大括號裡那七行
   貼進 `index.html` 最下面 `ARENA_CONFIG` 的 `firebase:` 區塊，取代原本的空字串。
5. 存檔、推上 GitHub。用手機或電腦打開網站，切幾個分頁。
6. 回到 Firebase 主控台 →「Analytics → Realtime」，30 秒內就會看到剛才那幾筆。

### 數據要去哪裡看

| 想看什麼 | 去哪裡 |
|---|---|
| 現在有沒有人在線上 | Firebase 主控台 → Analytics → **Realtime**（即時） |
| 這週有幾個人來、來幾次 | Firebase 主控台 → Analytics → Dashboard |
| **哪個分頁最多人看** | Google Analytics（GA4）→ 報表 → 參與 → **網頁和畫面**，把維度切成「**網頁標題**」 |

分頁名稱是用 `page_title` 送出去的，所以報表上會直接看到
「個人榜 / 公會戰 / 賽季日誌 / 刷題 / 設定」這五個中文名字。

> 完整報表在 GA4 那邊（Firebase 主控台的 Analytics 頁面右上角有連結可以跳過去）。
> 另外 GA4 的非即時報表會延遲數小時到一天，當天看不到數字是正常的，不是壞掉。

### 幾個常見疑問

- **金鑰貼在 GitHub 上不要緊嗎？** 不要緊。Firebase 的網頁設定值本來就會出現在
  任何訪客都看得到的網頁原始碼裡，它是「專案識別碼」不是密碼。
- **本機直接雙擊 `index.html` 為什麼沒數據？** `file://` 開檔沒有網域，統計會自動跳過。
  要在本機測就用 `python3 -m http.server` 這種方式開 `http://localhost`。
- **學員手機開了廣告阻擋，統計會壞掉嗎？** 那台手機不會被統計到，但網站不受影響
  （載入失敗會靜靜略過）。所以數字看趨勢就好，不用當成精準人數。

## 鍵盤快捷鍵

| 鍵 | 動作 |
|----|------|
| `R` | 同步試算表 |
| `S` | 存檔本回合（需先解鎖設定） |
| `C` | 開啟頒獎典禮 |
| `1` `2` `3` `4` `5` | 切換個人榜 / 公會戰 / 賽季日誌 / 刷題 / 設定 |
| `Esc` | 關閉戰績卡或離開頒獎典禮 |

頒獎典禮中：`空白鍵` / `→` 揭曉下一位、`←` 回上一位、`Esc` 離開。

刷題作答中：`1`～`4` 選答案（選完自動跳下一題）、`←` `→` 換題、`Enter` 交卷。

## 上課時好用的幾個開關

- **隱藏分數**（設定 → 顯示）：只顯示名次不顯示分數。想公開排名但不想公開實際成績時用。
- **自動同步**：每 60 秒重讀試算表。投影在教室螢幕上，你在手機改分數，畫面自己更新。
- **關閉動畫**：投影機效能不好時可以關掉粒子與換位動畫。
